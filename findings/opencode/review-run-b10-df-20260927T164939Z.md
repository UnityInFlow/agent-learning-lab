**Verdict:** finding

**Verdict:** finding
**Failure:** Let run-agent.sh start a valid run and print its run UUID, then make http://127.0.0.1:8081 unavailable before curl reads the record. REC becomes empty; the jq calls fail, but set -uo pipefail does not stop ordinary failing commands, so the script writes RESULT.md with empty record-derived fields and exits 0. ### the post-run sweep, diffed against the inventory
**Verdict:** finding
**Failure:** Suppose /tmp/policy-events-unknown.jsonl has 5 lines before the run and is truncated concurrently to 3 lines afterward. The before row is “path<TAB>5” and the after row is “path<TAB>3”; comm -13 reports the after row as new-or-grown even though the file shrank. RESULT.md therefore records one apparent hook-execution signal where none occurred.
**Layer of the implied fix:** L2
**Anchor:** NEW_OR_GROWN="$(LC_ALL=C comm -13 "$EVID/sweep-before.tsv" "$EVID/sweep-after.tsv" | wc -l | tr -d ' ')"

### Cross-cutting
**Verdict:** finding
**Failure:** The executable-bit overlay gate and the positive-control gate are pass/fail controls and are not duplicated by the reported DF-P1–DF-P4 measurements. Reviewers will diverge most on “the post-run sweep”: for a pre-existing log changing from 5 to 3 lines, one will count 1 new-or-grown while another will count 0, a one-event difference that can reverse DF-P2. The artifact does not say how it excludes unrelated concurrent writers or truncators of policy-events-*.jsonl; a separate process appending one line during the run produces the same reported observation as the tested hook.
**Layer of the implied fix:** L2
**Anchor:** inventories EVERY policy-events-*.jsonl in $TMPDIR and /tmp BEFORE the run and diffs the inventory afterwards, by name AND by line count.
