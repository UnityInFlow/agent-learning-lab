WHAT HAPPENED
  $TMPDIR is /var/folders/.../T/, which macOS reaps periodically: it deletes FILES
  not accessed for ~3 days and leaves the DIRECTORY TREE standing. The observatory
  keeps scored worktrees there under --keep, so a run's evidence hollows out while
  its directory continues to exist.

WHY THIS IS THE HOUSE FAILURE MODE
  The scorer's message is 'the agent changed no source file ... That is a result
  about the run'. It is not. It is a result about the operating system. An
  environmental loss is being reported as agent behaviour, which GUARDRAILS.md
  names as the single most common way a guardrail corrupts a measurement, and
  which this project already paid for once as harness bug #7.

  Nothing here changes a score already on disk. The five sheets were produced on
  2026-08-30 and 2026-09-01 while the files were present. What is lost is the
  ability to RE-DERIVE them, which is what validation requires.
